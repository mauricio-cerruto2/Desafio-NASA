2. Formulación del modelo matemático

El cohete está sometido a tres fuerzas principales:

  • Empuje del motor: T.
  • Peso del cohete: mg.
  • Resistencia del aire: kv.
Segunda ley de Newton:
m · dv/dt = T - mg - kv
Ecuación diferencial de velocidad:
dv/dt = T/m - g - (k/m)v
Ecuación diferencial de altura:
dy/dt = v

Condiciones iniciales:

v(0) = v₀
y(0) = y₀

8. Solución analítica

Definimos:

a = T/m - g
b = k/m

Cuando b es diferente de cero, la solución analítica de velocidad es:

v(t) = a/b + (v₀ - a/b)e-bt

La solución analítica de altura es:

y(t) = y₀ + (a/b)t + (v₀ - a/b)(1-e-bt)/b

Cuando b = 0, las ecuaciones son:

v(t) = v₀ + at
y(t) = y₀ + v₀t + ½at²

11. Limitaciones del modelo

  • Se considera una masa constante.
  • El empuje del motor permanece constante.
  • La gravedad se considera constante.
  • La resistencia del aire se representa mediante un modelo lineal.
  • No se consideran el viento ni los movimientos laterales.
  • No se simula una trayectoria orbital real.

Este es un modelo académico simplificado. Sus parámetros son didácticos y no representan datos oficiales de la NASA.
